# 🤖 Robot School Quiz

Сайт для живих онлайн-вікторин у стилі Kahoot для учнів Robot School.

**Учні** відкривають посилання, вводять код гри й нікнейм, збирають власного робота (5 корпусів, 12 кольорів, очі, рот, антени, 9 шапок, окуляри, прикраси, предмети в руках, фон) і грають зі свого телефона, планшета чи комп'ютера. Реєстрація не потрібна.

**Учитель** входить у кабінет за адресою `/admin`:

- логін `robotschool`, пароль `bender2015` (вони фіксовані й задані у `server.js`);
- генерує квіз через ШІ-помічника: обирає напрямок (3D-графіка, робототехніка або програмування), кількість питань, час на відповідь, теми, вік, складність і типи питань;
- редагує все, що є в квізі: назву, напрямок, час, тип кожного питання, текст, варіанти й правильні відповіді, бали (звичайні, подвійні або без балів), емодзі та цікавий факт. Окреме питання можна замінити або додати через ШІ;
- зберігає квізи на сайті й запускає їх із кабінету: на великому екрані з'являються код гри та QR-код, а далі питання, статистика відповідей, таблиця лідерів і подіум із конфеті.

## Типи питань

| Тип | Як грає учень |
|---|---|
| 🎯 Одна відповідь | натискає один із 4 кольорових варіантів |
| ⚖️ Правда / неправда | 👍 або 👎 |
| ✅ Кілька відповідей | вибирає всі правильні варіанти й натискає «Відповісти» |
| 🔢 Розстав по порядку | переставляє кроки стрілками ▲▼ |
| ⌨️ Вписати відповідь | вводить слово або число; регістр і лапки не враховуються |

Бали залежать від швидкості відповіді: від 500 до 1000, а за подвійні — від 1000 до 2000. За серію правильних відповідей поспіль 🔥 нараховується бонус. Після кожного питання учень бачить, чи відповів правильно, своє місце в рейтингу, скільки балів йому бракує до суперника попереду, і цікавий факт.

## Приватність

- Нікнейми, роботи й бали зберігаються **лише в оперативній пам'яті** сервера, поки триває гра. Після фіналу кімната повністю видаляється. Нікуди на диск ці дані не записуються.
- На диск (`data/quizzes.json`) потрапляють тільки квізи вчителя.
- Нікнейми з лайкою відхиляються. Учитель може вигнати гравця, натиснувши на нього в лобі, або закрити вхід до гри.

## Запуск на комп'ютері вчителя (Windows)

1. Встановіть [Node.js](https://nodejs.org) (версія LTS).
2. Розпакуйте архів і двічі клацніть `start.bat`. Під час першого запуску встановляться залежності, після чого відкриється кабінет учителя.
3. Учні в тій самій мережі Wi-Fi заходять за адресою, яку показує екран гри, наприклад `http://192.168.1.15:3000`, або сканують QR-код.

> Якщо учні не можуть підключитися, дозвольте Node.js у брандмауері Windows для приватних мереж.

Запуск із терміналу на будь-якій ОС: `npm install`, а потім `npm start`.

## Доступ через інтернет (GitHub + Render)

GitHub Pages не підходить: він вміє показувати лише статичні сторінки, а грі потрібен сервер. Тому код зберігається на **GitHub**, а запускається на **Render**, який безкоштовно бере код прямо з GitHub. Квізи вчителя записуються назад у GitHub, в окрему гілку `quiz-data`, тож нікуди не зникають.

1. **Репозиторій.** На github.com створіть новий репозиторій, обов'язково **Private**, бо пароль адміна записаний у коді. Натисніть *uploading an existing file* і перетягніть усі файли та папки проєкту, крім `node_modules` і `.env`. Потім *Commit changes*.
2. **Токен для збереження квізів.** Відкрийте *Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token*. У полі *Repository access* виберіть *Only select repositories* і свій репозиторій. У розділі *Permissions → Contents* поставте **Read and write**. Скопіюйте токен (`github_pat_…`).
3. **Render.** Зареєструйтеся на render.com через GitHub і виберіть *New → Web Service*. Дозвольте доступ до репозиторію і вкажіть:
   - Build Command: `npm install`, Start Command: `npm start`, Instance Type: **Free**;
   - у розділі *Environment Variables* додайте `GITHUB_REPO` = `ваш-логін/назва-репозиторію` і `GITHUB_TOKEN` = токен із кроку 2. За бажанням додайте ключ ШІ (`GEMINI_API_KEY`), див. розділ «ШІ-помічник».
4. Натисніть *Deploy*. За кілька хвилин сайт запрацює за адресою на кшталт `https://robot-school-quiz.onrender.com`. Учні заходять туди, а вчитель — на `/admin`. У журналі (*Logs*) має з'явитися рядок «Квізи зберігаються в GitHub ✅».

Особливості безкоштовного Render:

- Якщо на сайт ніхто не заходить 15 хвилин, він «засинає». Перший вхід після цього триває до хвилини, тому відкрийте `/admin` за 2–3 хвилини до уроку.
- Зв'язок інколи ненадовго обривається. Сайт сам перепідключає учнів і вчителя, і гра продовжується з того самого місця.
- Без затримок і обривів працює платний тариф Render Starter.

Після змін у коді достатньо завантажити оновлені файли в репозиторій (гілка `main`), і Render сам оновить сайт.

## ШІ-помічник

Без ключів генератор збирає квізи з вбудованої бази. Це близько 60 перевірених питань із 3D-графіки, робототехніки й програмування. Щоб ШІ складав **нові** питання на будь-які теми, підключіть один із сервісів:

| Сервіс | Ціна | Де взяти ключ | Змінна |
|---|---|---|---|
| **Google Gemini** (рекомендовано) | безкоштовно, з лімітом запитів | [aistudio.google.com/apikey](https://aistudio.google.com/apikey) → *Create API key* | `GEMINI_API_KEY` |
| **Groq** (запасний) | безкоштовно, з лімітом запитів | [console.groq.com/keys](https://console.groq.com/keys) → *Create API Key* | `GROQ_API_KEY` |
| Claude API | платно | [console.anthropic.com](https://console.anthropic.com) | `ANTHROPIC_API_KEY` |

На Render ключ додають у сервісі → **Environment → Add Environment Variable**, а потім натискають **Save Changes**. Локально ключ записують у файл `.env`.

- Якщо підключено кілька сервісів, сайт пробує їх по черзі. Якщо всі недоступні, квіз збирається з вбудованої бази.
- Безкоштовні тарифи мають ліміти, тому великий квіз генерується частинами і може зайняти 1–2 хвилини.
- ШІ отримує лише параметри, які вказав учитель. Дані учнів туди не потрапляють.
- Ключі зберігаються тільки на сервері й ніколи не потрапляють у браузер.

## Структура

```
server.js            сервер: вхід, квізи, ШІ, ігрові кімнати (Socket.IO)
lib/store.js         збереження квізів у data/quizzes.json
lib/ai.js            генерація через Gemini / Groq / Claude API
lib/bank.js          вбудована база питань (офлайн-режим)
public/index.html    сторінка учня
public/admin.html    кабінет учителя та екран ведучого
public/js/avatar.js  конструктор робота (SVG)
public/js/fx.js      звуки, конфеті
```
